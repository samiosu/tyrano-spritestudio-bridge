## 配布ページ用の説明文

**Tyrano SpriteStudio Bridge v0.1.0（非公式）**

ティラノスクリプトV6で、SpriteStudioのアニメーションを表示できるプラグインです。
フォルダーのコピーと、シナリオへの数行の追記で使えます。
「はじめに.txt」に3ステップの導入手順があり、同梱の青い図形で動作を試せます。
自分の素材の使い方、動きの切り替え、位置・大きさの調整にも、コピーして使える例を付けています。

ダウンロードするファイル：**`tyrano-spritestudio-0.1.0.zip`**
解凍したら、最初に **「はじめに.txt」**を開いてください。

自分の素材は、公式のSs6Converterで変換した `.ssfb` と、その素材に使う画像を用意してください。
ティラノスクリプトV603bを、Linux環境のChromium・Firefox・WebKitで確認しています。
スマートフォン画面の模擬操作も確認済みです。Windows・macOS、スマートフォン実機、ティラノスタジオ、PCアプリは未確認です。

作者：さみおす／ライセンス：MIT（連携コード・独自サンプル）
同梱ライブラリにはそれぞれの条件があります。再配布時もlicensesフォルダーを含めてください。
このプラグインは非公式で、各ソフトウェア提供元の認定を表すものではありません。

## 利用者に見せる案内

利用者向けZIPへのリンクと「はじめに.txt」への案内を、ダウンロードページの最初に置きます。
ソースZIP、ハッシュ、内部仕様は「開発者向け」として末尾にまとめます。
SHA-256の確認は任意です。通常の導入手順には含めません。

導入は「フォルダーをコピー → first.ksへサンプルを追記 → make.ksへ2行を追記」で説明します。
コピー先、ファイル名、追加する位置、成功時に見える青い図形を明記してください。
既存シナリオへの導入では追記を案内します。
`examples/first.ks` は新規テストプロジェクト用、`examples/advanced.ks` は応用サンプルです。

## 配布物と作成手順（開発者向け）

| ファイル | 内容 |
| --- | --- |
| `tyrano-spritestudio-0.1.0.zip` | 利用者向け。本体・素材・「はじめに.txt」・使用例・説明書・ライセンス |
| `tyrano-spritestudio-0.1.0-source.zip` | 上記にソース・固定した依存情報・ビルドスクリプト・テストを追加 |
| `SHA256SUMS.txt` | ZIPの破損・取り違えを確認する任意のSHA-256ハッシュ |

[開発手順](DEVELOPMENT.md) に従ってビルド・確認・ZIP作成を行います。
同梱資料だけを変更する場合も、ZIPとハッシュを作り直してください。
作成したZIPとハッシュを `releases/v0.1.0/` に反映し、Releaseの説明とダウンロードリンクを更新します。
現在のReleaseでは、リポジトリ内の配布ファイルへのリンクを使用しています。
ソースや資料のリンクも、配布物と一致するコミットに固定します。

新しいバージョンを配布する場合は、バージョン番号・変更履歴・配布先フォルダーを更新し、
確認済みのコミットに対応するタグとReleaseを作成してください。
現在の非公開リポジトリを一般公開する場合は、GitHubで可視性を変更します。

配布するのはプラグインと独自のサンプル素材です。
ティラノ本体や他者のキャラクター素材を追加する場合は、それぞれの再配布条件を確認してください。
