## 公開ページ用の説明文

**Tyrano SpriteStudio Bridge v0.1.0（非公式）**

作者：さみおす／ライセンス：MIT（連携コード・独自サンプル）
個別サポート・導入支援は提供しません。
GitHubのIssue・Pull Requestには対応する場合があります。返信・対応は保証しません。

ティラノスクリプトV6で、SpriteStudioのアニメーションを表示・操作できるプラグインです。
SS6PlayerForWebを使用し、変換済みSSFBデータの読み込み、モーション切り替え、ループ再生、
再生待ち、一時停止、位置・透明度の変更、複数表示、セーブ・ロード復元に対応します。
依存ライブラリを同梱しており、実行時にCDNへ接続する必要はありません。
導入手順と独自の図形アニメーションサンプルが付属します。

検証環境：ティラノスクリプトV603b、Chromium 154のHTTP配信環境。
PC／スマートフォンへのパッケージ化、Safari、Firefox、スマートフォン実機は未検証です。
SpriteStudioプロジェクトはSs6ConverterでSSFBに変換してください。
SS6PlayerForWeb側の対応範囲を超える描画機能は利用できません。

## 配布物

## GitHubで公開する場合

1. 非公開リポジトリを一般公開する場合は、GitHubで可視性を変更します。
2. ソースZIPの内容をリポジトリのルートへ配置します。
3. READMEの導入例と制限を確認し、`npm ci` → `npm run build` → `npm test` を実行します。
4. タグ `v0.1.0` を作成し、Releaseへ利用者向けZIPとソースZIP、ハッシュファイルを添付します。
5. 配布ページに「作者：さみおす」「ライセンス：MIT」と、上記のサポート方針を記載します。

現在は非公開で保管しています。Issue・Pull Requestでの報告や提案には対応する場合があります。
個別サポート・導入支援、返信・対応の保証は提供しません。

配布するのはプラグインとサンプル素材です。ティラノ本体や他者のキャラクター素材を
ソースやZIPへ追加する際は、それぞれの再配布条件を別途確認してください。
