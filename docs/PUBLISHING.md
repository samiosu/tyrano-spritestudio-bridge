## 配布ページ用の説明文

**Tyrano SpriteStudio Bridge v0.1.1（非公式）**

ティラノスクリプトV6で、SpriteStudioのアニメーションを表示できるプラグインです。
フォルダーのコピーと、シナリオへの数行の追記で使えます。
「はじめに.txt」に3ステップの導入手順があり、同梱の青い図形で動作を試せます。
自分の素材の使い方、動きの切り替え、位置・大きさの調整にも、コピーして使える例を付けています。

ダウンロードするファイル：**`tyrano-spritestudio-0.1.1.zip`**
解凍したら、最初に「**はじめに.txt**」を開いてください。

自分の素材は、公式のSs6Converterで変換した `.ssfb` と、その素材に使う画像を用意してください。
次の動作確認は0.1.0の結果です。0.1.1では終了待ちを修正し、変更後の実行テストは行っていません。
Codexが、ティラノスクリプトV603bの動作をLinux環境のChromium・Firefox・WebKitで確認しました。
スマートフォン画面の模擬操作もCodexが確認しました。
Windows 11・TyranoStudio Ver6.0.0のゲーム再生機能で、配布ZIPの同梱データとSpriteStudio公式サンプルデータの実行も確認済みです（作者さみおすによる確認）。
Windows・macOSのブラウザ、スマートフォン実機、書き出したPCアプリは未確認です。

作者：さみおす／ライセンス：MIT（連携コード・独自サンプル）

## 利用者に見せる案内

利用者向けZIPへのリンクと「はじめに.txt」への案内を、ダウンロードページの最初に置きます。
ソースZIP、ハッシュ、内部仕様は「開発者向け」として末尾にまとめます。
SHA-256の確認は任意です。通常の導入手順には含めません。

導入は「フォルダーをコピー → first.ksへサンプルを追記 → make.ksへ2行を追記」で説明します。
コピー先、ファイル名、追加する位置、成功時に見える青い図形を明記してください。
既存シナリオへの導入では追記を案内します。
`examples/first.ks` は新規テストプロジェクト用、`examples/advanced.ks` は応用サンプルです。

## 配布物と作成手順（開発者向け）

| ファイル | 内容 |
| --- | --- |
| `tyrano-spritestudio-0.1.1.zip` | 利用者向け。本体・素材・「はじめに.txt」・使用例・説明書・ライセンス |
| `tyrano-spritestudio-0.1.1-source.zip` | 上記にソース・固定した依存情報・ビルドスクリプト・テストを追加 |
| `SHA256SUMS.txt` | ZIPの破損・取り違えを確認する任意のSHA-256ハッシュ |

[開発手順](DEVELOPMENT.md) に従ってビルド・確認・ZIP作成を行います。
同梱資料だけを変更する場合も、ZIPとハッシュを作り直してください。
作成したZIPとハッシュを `releases/v0.1.1/` に反映します。
Release作成後、次の3ファイルを「Assets」に添付します。
リポジトリへの保存や本文へのリンクだけでは、Releaseの添付ファイル欄には表示されません。

```sh
gh release upload v0.1.1 \
  releases/v0.1.1/tyrano-spritestudio-0.1.1.zip \
  releases/v0.1.1/tyrano-spritestudio-0.1.1-source.zip \
  releases/v0.1.1/SHA256SUMS.txt \
  --repo samiosu/tyrano-spritestudio-bridge
```

GitHub Actionsから添付する場合は、「Actions」→「Attach release downloads」→「Run workflow」で、
ブランチ `main` と対象のタグを選びます。
このワークフローは、コミット済みの配布ZIPとハッシュを照合して既存のReleaseへ添付し、説明文も更新します。
ビルドやゲームの実行テストは行いません。既に同名の添付ファイルがある場合は、上書きせずに停止します。

その後、Releaseの説明とダウンロードリンクを更新します。
添付ファイルへのリンクは `/releases/download/<タグ>/<ファイル名>` の形式を使用します。
資料は `/blob/<コミット>/<パス>` の形式で、配布物と一致するコミットに固定します。
「Assets」に3ファイルが表示され、ダウンロードしたZIPとハッシュが配布元と一致することを確認します。
GitHubが自動生成する `Source code (zip)` と `Source code (tar.gz)` は、リポジトリ全体のアーカイブです。
ゲームへの導入用には `tyrano-spritestudio-0.1.1.zip` を案内してください。

新しいバージョンを配布する場合は、バージョン番号・変更履歴・配布先フォルダーを更新し、
確認済みのコミットに対応するタグとReleaseを作成してください。
一般公開するときは、資料と配布ZIPを反映してから、GitHubのリポジトリ設定で可視性を `Public` に変更します。
リポジトリ、Release、ZIPのダウンロードを、ログインしていない状態でも開けることを確認します。

配布するのはプラグインと独自のサンプル素材です。
ティラノ本体や他者のキャラクター素材を追加する場合は、それぞれの再配布条件を確認してください。
