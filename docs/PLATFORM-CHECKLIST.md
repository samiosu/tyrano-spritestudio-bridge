# 実環境の確認手順

開発者が追加の対応環境を確認するための資料です。
ここにある試験は、このリポジトリのLinux検証では実施していません。
実施済みの結果は [検証記録](VALIDATION.md) を参照してください。

## 記録する環境

OS・端末名、ブラウザまたはティラノスタジオのバージョン、ティラノ本体のバージョン、
プラグインのコミット、使用素材、起動方法と結果を記録します。
ブラウザで試した結果と、書き出したアプリの結果は分けて記録してください。

| 環境 | このリポジトリの実機検証 |
| --- | --- |
| Windows：Chrome／Firefox、ティラノスタジオのプレビューとPC書き出し | 未実施 |
| macOS：Safari、ティラノスタジオのプレビューとPC書き出し | 未実施 |
| iOS：Safari、対象とするアプリ形式 | 未実施 |
| Android：Chrome、対象とするアプリ形式 | 未実施 |

## 基本動作

1. 公式V6のテストプロジェクトに、[README](../README.md) の3ステップで導入する。
2. 青い図形が動き、文章のクリック／タッチで消えることを確認する。
3. 新しいテストプロジェクトで `examples/advanced.ks` を実行し、動きの切り替え・一時停止／再開・位置変更を確認する。
4. 図形を表示したままティラノ標準のメニューでセーブし、位置や状態を変えてからロードする。保存した位置と再生状態に戻り、表示が重複しないことを確認する。
5. ティラノスタジオでは同じプロジェクトのプレビューと、公式の書き出し機能で作ったアプリの両方を起動する。プラグインとSSFB・画像が書き出し先にも含まれていることを確認する。
6. スマートフォン実機では縦・横、タッチ、背景への移動と復帰、ロード後のタッチを確認する。

ブラウザ版はHTTP(S)配信で確認します。HTMLのダブルクリック起動は対応対象に含めません。
失敗した場合は、どの操作で止まったかと、取得できるエラーを記録します。

## 自分の素材と継続動作

実際に使用するSSFBと画像で、使うモーション・メッシュ・ボーン・ブレンド・マスク・エフェクトを確認します。
独立したインスタンスパーツはセーブ前後の状態も確認してください。

対象のブラウザまたはアプリで、再生・切り替え・削除・セーブ復元を繰り返します。
数時間の動作を評価する場合は、その時間を実際に測定し、表示数とメモリ推移を記録してください。
自動継続試験の `tests/soak.mjs` は、ChromiumのJavaScriptヒープを測るためのもので、実機やGPUメモリの試験を置き換えません。
